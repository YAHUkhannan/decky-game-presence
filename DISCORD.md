**Game Presence** — Decky plugin

Shows the game you are playing on Discord while you are in Game Mode. No Discord tab, no overlay window. Friends see a normal Playing status with the official title and art.

**Install (easiest):** download the zip from Releases, then Decky → settings → Developer mode → Install Plugin from ZIP. Paste this URL if it asks for one:
https://github.com/YAHUkhannan/decky-game-presence/releases/latest/download/GamePresence-1.1.0.zip

**Vs the usual Discord Status plugin:** that one needs Discord open as a Game Mode tab. This one does not. It uses Discord’s official game name and art, and still reports titles Steam does not list in the overlay.
